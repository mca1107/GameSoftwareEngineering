탐험 끝에 발견하는 '새벽망'은 물자와 정보를 연결하는 분산 기반망이다.
새벽망은 자원을 무한히 만들거나 사람의 마음을 강제로 치유하지 않는다.
복구에는 지역 주민들의 기술, 자원, 참여 의사가 필요하다.
이야기의 핵심 갈등은 연결을 통한 회복과 안전을 명분으로 한 통제 사이에 있다.

포스트 아포칼립스 적용 초안 — 분위기는 확정되었으며 아래 세부 설정은 제안이다.
재난 이후 폐허, 오염지대, 단절된 정착지를 중심으로 세계를 구성한다.
새벽망은 남은 정수·전력·통신 시설을 연결한다. 재난의 구체적 원인은 미정이다.

5. 메인 퀘스트 트리 초안
표기: MQ는 메인 퀘스트 ID. 선택은 퀘스트 내부의 해결 방식이다.
병렬 지역은 순서만 자유로우며 세 지역의 메인 퀘스트는 모두 진행한다.

MQ00 꺼지지 않은 신호 [프롤로그]
  └─ MQ01 첫 번째 불빛 [첫 정착지]
       └─ MQ02 끊어진 지도 [지역 탐험 개방]
            ├─ MQ03A 마르지 않는 약속 [물의 구역]
            ├─ MQ03B 지워진 목소리 [기록의 구역]
            └─ MQ03C 서로의 온기 [전력의 구역]
                 ※ MQ03A/B/C 모두 완료하면 합류
                      └─ MQ04 신호 너머의 사람들 [중간 전환]
                           └─ MQ05 빛의 대가 [최종 선택 준비]
                                └─ MQ06 새벽을 잇는 날 [결말 선택]
                                     ├─ E1 함께 켜는 새벽
                                     ├─ E2 관리되는 낙원
                                     └─ E3 작은 불빛들의 세계
                                          └─ MQ07 내일의 풍경 [공통 에필로그]

MQ00 꺼지지 않은 신호
- 목표: 이동·상호작용을 익히고 폐쇄 중계소에서 구조 신호를 복원한다.
- 사건: 수신된 메시지는 오래된 기록처럼 보이지만 현재의 응답을 포함한다.
- 완료 조건: 중계소 조사 및 신호 좌표 확보.
- 결과: 첫 정착지 위치와 탐험 동기를 제공한다.

MQ01 첫 번째 불빛
- 목표: 첫 정착지의 통신과 최소한의 생존 설비를 복구한다.
- 선택: 위험 지역에서 부품을 회수하거나, 인근 집단과 교환 조건을 협상한다.
- 완료 조건: 어느 해결 방식으로든 설비 가동 및 주민과 대화.
- 결과: 거점 이용이 가능해지고, 작은 행동이 사람들의 일상을 바꾸는 모습을 보여준다.
- 설계 의도: 세계 전체의 구원보다 눈앞의 한 공동체를 먼저 경험하게 한다.

MQ02 끊어진 지도
- 목표: 세 지역의 중계 좌표와 새벽망에 관한 기록을 찾는다.
- 완료 조건: 지도 복원 및 세 지역의 요청 확인.
- 결과: MQ03A/B/C를 동시에 개방한다. 방문 순서는 플레이어가 정한다.
- 설계 의도: 메인 목표는 명확히 유지하면서 주변 탐험은 자유롭게 한다.

MQ03A 마르지 않는 약속 — 물의 구역
- 목표: 물 공급을 둘러싼 갈등을 해결하고 지역 연결 장치를 확보한다.
- 선택: 주민 공동 운영 / 기존 관리자의 통제 아래 공급 보장.
- 완료 조건: 공급 시설 복구와 운영 주체 결정.
- 결과: A 지역 연결 준비 완료. 물 접근성과 주민 신뢰가 선택에 따라 달라진다.
- 희망의 표현: 생존 자원이 실제로 주민에게 돌아오는 장면.

MQ03B 지워진 목소리 — 기록의 구역
- 목표: 실종자와 붕괴 원인에 관한 기록을 복구한다.
- 선택: 증언자의 동의를 얻어 공개 / 신원 보호를 위해 제한 공개.
- 완료 조건: 기록의 진위 확인과 공개 범위 결정.
- 결과: B 지역 연결 준비 완료. 증언자 신뢰와 공공 정보 접근성이 달라진다.
- 희망의 표현: 잊힌 사람들의 이름과 관계를 되찾는 장면.
- 주의: 공개를 무조건 선, 보호를 무조건 악으로 처리하지 않는다.

MQ03C 서로의 온기 — 전력의 구역
- 목표: 제한된 전력의 배분을 둘러싼 두 공동체의 충돌을 해결한다.
- 선택: 공동 배분 협약 / 핵심 시설 우선 배분 후 복구 계획 마련.
- 완료 조건: 발전 설비 안정화와 배분 원칙 결정.
- 결과: C 지역 연결 준비 완료. 지역 협력과 기반 안정성이 달라진다.
- 희망의 표현: 어둠 속 주거지나 치료 시설에 전기가 돌아오는 장면.

MQ04 신호 너머의 사람들
- 시작 조건: MQ03A/B/C 모두 완료.
- 목표: 중앙 중계소에 도착해 신호의 발신자를 만난다.
- 반전: 신호는 한 명의 구원자가 아니라 여러 지역 생존자들이 이어 보낸 것이다.
- 갈등: 중앙 관리 체계는 재붕괴를 막으려면 통합 통제가 필요하다고 주장한다.
- 완료 조건: 새벽망의 기능·한계와 양측의 주장을 확인한다.
- 결과: 복구의 목적이 '장치 찾기'에서 '어떤 연결을 만들 것인가'로 바뀐다.

MQ05 빛의 대가
- 목표: 최종 가동에 필요한 부품, 전력, 지역별 참여 결정을 확보한다.
- 이전 선택의 반영: 협력 지역은 자원·인력을 지원하고 불신 지역은 보완 조건을 요구한다.
- 회복 경로: 지원이 부족하면 메인 퀘스트 내 추가 협상·회수 목표로 보완할 수 있다.
- 완료 조건: 최소 가동 자원 확보 및 세 지역의 참여 조건 확정.
- 결과: 각 최종 선택의 비용과 예상 영향을 선택 전에 설명한다.
- 주의: 과거 선택 때문에 필수 자원이 영구히 사라져 진행이 막히지 않게 한다.

MQ06 새벽을 잇는 날
- 목표: 중추 시설에 접근해 최종 연결 방식을 결정하고 가동한다.
- 전투 방식은 미정이므로 접근 수단은 전투·잠입·협상 후보로 남긴다.
- 완료 조건: 준비된 방식 중 하나를 선택하고 해당 가동 목표를 수행한다.
- E1 함께 켜는 새벽: 주민들이 관리하는 분산 연결망을 만든다.
  준비 조건: 세 지역의 자율 운영 참여 확보. 부족한 참여는 MQ05에서 보완 가능.
  결과: 회복은 느리지만 주민들이 운영 권한과 책임을 함께 가진다.
- E2 관리되는 낙원: 중앙 관리 체계에 통합 운영을 맡긴다.
  준비 조건: 중앙 운영 협약 확보.
  결과: 기반 회복은 빠르지만 감시와 자율성 제한이라는 대가가 남는다.
- E3 작은 불빛들의 세계: 중앙 연결 대신 각 지역의 독립 기반을 유지한다.
  준비 조건: MQ05에서 각 지역의 최소 독립 생존 설비 확보.
  결과: 광역 회복은 제한되지만 지역별 삶과 자유를 지킬 출발점이 생긴다.
- 의도: 모든 결말에 희망과 대가가 함께 존재하며, 한 선택을 단순한 실패로 취급하지 않는다.

MQ07 내일의 풍경
- 목표: 변화한 정착지와 사람들을 다시 방문한다.
- 반영 요소: 지역의 물·기록·전력 결정, 협력 상태, 최종 연결 방식.
- 완료 조건: 주요 지역의 후일담 확인.
- 결과: 완벽한 세계가 아닌 '내일을 기대할 수 있는 세계'를 보여준다.
- 엔딩 후 자유 탐험 지원 여부와 구현 범위는 별도 결정한다.

6. 오픈월드와 퀘스트 설계 원칙 제안
- 자유로운 지역 탐험과 메인 퀘스트 진행 순서를 구분한다.
- 스토리상 필수 시설만 진행 조건으로 제한하고, 지역 전체를 불필요하게 막지 않는다.
- 병렬 퀘스트 완료 순서가 달라도 대사와 합류 조건이 성립해야 한다.
- 선택 결과는 대사뿐 아니라 주민 배치, 시설 상태, 접근 권한 등으로 표현한다.
- 메인 진행에 필수인 정보를 선택형 서브 퀘스트에만 숨기지 않는다.
- 최종 선택의 조건과 비용을 미리 보여주고, 보완 기회를 제공한다.
- 퀘스트 상태는 미시작·진행 중·완료 및 결정 값을 분리해 저장하는 방향을 검토한다.
- 반복 대화나 재방문으로 보상이 중복 지급되지 않도록 설계한다.
- 월드 크기, 지역 로딩 방식, 저장 시스템의 구체적 사양은 아직 미정이다.

7. 현재 기술 기반과 진행 상태
- 후속 구현: TutorialLevel.h/.cpp에 WASD/F 튜토리얼, 물자 회수 퀘스트,
  코드 도형 기반 쿼터뷰 장면과 한글 UI를 추가했다. 아래 기존 분석 기록과 구분한다.
- 후속 구현은 빌드·실행하지 않았다. 현재 확인 범위는 튜토리얼_구현_안내.txt를 참고한다.
- 기존 기반: SimpleGame.sln의 단일 C++ 실행 프로그램 프로젝트.
- 사용 기술: Windows, Visual Studio/MSBuild, OpenGL, GLEW, freeglut, GLSL.
- 프로젝트 설정: v145 도구 집합, Windows SDK 10.0, Debug/Release 및 x86/x64.
- 기존 분석에서 확인한 구현: 창 생성, 입력 콜백, 셰이더 로딩, 사각형 렌더링.
- 당시 코드의 입력 콜백은 이동 같은 게임 상태를 변경하지 않았다.
- 월드·RPG 시스템·메인 퀘스트가 구현되었다는 확인은 없다.
- 과거 분석 시 Debug/x64 빌드에 성공했다. 이는 당시 소스에 대한 기록이다.
- 이번 작업은 기획 문서 작성이며 현재 소스를 다시 빌드하거나 실행하지 않았다.
- 이전 정적 검토에서 찾은 개선 항목:
  셰이더 실패값의 unsigned 변환, 상대 경로 의존, 초기화 검사,
  창 크기 변경 대응, GPU 자원 정리, 업데이트와 렌더링 분리.
  수정에 착수할 때 현재 코드에서 각 항목의 잔존 여부를 다시 확인한다.

8. 개발 단계 제안 — 구현 지시가 아닌 이후 계획
1단계: 초기화·자원 경로·종료 처리 등 렌더링 기반 정리.
2단계: 작은 테스트 공간에서 쿼터뷰 표현, 캐릭터 이동, 카메라, 가림 순서 구현.
3단계: 상호작용·대화·퀘스트 상태·저장 불러오기의 최소 흐름 구현.
4단계: MQ00~MQ01을 작은 지역에서 처음부터 끝까지 플레이할 수 있게 제작.
5단계: 세 지역 탐험과 선택 결과를 확장하고 MQ02~MQ07을 연결.
6단계: 확정된 월드 규모에 맞춰 지역 로딩과 렌더링 성능 개선.
대규모 콘텐츠 제작 전 첫 지역에서 탐험과 희망이라는 경험이 성립하는지 확인한다.

9. 아직 결정하지 않은 사항
- 정확한 시대, 붕괴 원인, 지명, 주인공의 이름과 개인적 과거.
- 스프라이트 / 3D / 혼합 표현, 아트 스타일 및 자산 제작 방식.
- 전투 유무와 세부 방식, 성장·장비·제작·생존 시스템의 범위.
- 월드 크기, 플레이 시간, 입력 장치, 목표 성능, 저장 방식.
- 위 플레이 시간은 전체 게임 기준이다. 현재 튜토리얼은 5분 이내, 조작은 WASD/F로 확정되었다.
- 위 메인 퀘스트 초안의 인물·갈등·결말과 각 구현 범위.
미정 사항은 확정 사실처럼 코드나 후속 문서에 반영하지 않는다.

10. Codex 협업 지침
- 이 문서의 확정 사항과 AGENTS.md를 작업 기준으로 삼는다.
- 기존 사용자 변경을 보존하고, 요청한 범위 안에서 분석·설계·수정한다.
- 특별한 상황이 아니라면 빌드와 실행 결과 확인은 사용자가 직접 수행한다.
- 기본적으로 정적 검토와 수정까지만 진행한다.
- 사용자가 명시적으로 요청하거나 예외적으로 필요할 때만 빌드·실행을 수행한다.
  예외가 필요하면 이유를 먼저 설명한다.
- 완료 보고에는 직접 확인한 범위와 사용자 확인 사항을 구분한다.
- 사용자 결정과 제안을 구분하고, 새로운 결정은 이 문서와 AGENTS.md에 일관되게 반영한다.
- 기획 변경 요청 없이 오픈월드 RPG, 싱글 플레이, 미래 배경, 포스트 아포칼립스 분위기, 쿼터뷰 2.5D,
  망가진 세계에서 희망을 찾는 핵심 방향을 바꾸지 않는다.

장미 복장 확정: 후드티와 트레이닝 바지. 현재 게임에서는 후드티 가슴의 장미 문양으로 장미 컨셉을 표현한다. 검은 고양이 수인 설정은 유지하며, 세분화된 도형 모델을 캐싱한다.

최신 제목 및 외형 변경
- 한국어 제목: 여우와 장미 / 영어명: Fox And Rose / 약칭: FAR.
- 표지는 한국어 제목, 창 제목과 실행 파일 이름은 Fox And Rose로 변경한다.
- 표지 여우의 앞다리를 안쪽으로 기울여 앞발을 가까이 배치한다.
- 인게임 여우의 모자를 모든 방향에서 제거한다. 머리카락은 숨기는 설정을 유지한다.
- 인벤토리 왼쪽은 원래 색상으로 캐릭터 모델을 표시한다.
- 이전 제목, 모자, 어두운 실루엣 지침보다 이 내용을 우선한다.
