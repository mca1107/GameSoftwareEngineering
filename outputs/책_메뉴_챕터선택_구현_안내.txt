책 표지 메인화면 및 챕터 선택 구현 안내

1. 화면과 조작
- 실행 시 닫힌 책 표지로 진입한다. 기존 가칭 제목 '새벽의 신호'와 게임 종료 버튼만 표시한다.
- 표지 삽화는 기존 엔진의 도형 렌더러로 그린 폐허, 식물, 달과 별, 여우와 검은 고양이다.
- 표지 클릭: 약 0.85초 동안 책등을 축으로 표지가 열리고 챕터 선택으로 이동한다.
- 펼친 책에는 1–2, 3–4, 5–6, 7–8을 두 페이지씩 배치한다.
- 페이지마다 챕터 번호, 제목, 세 줄의 소개, 시작 가능 여부를 표시한다.
- 왼쪽 아래 접힌 모서리: 이전 펼침면. 첫 펼침면에서는 책을 닫아 메인화면으로 돌아간다.
- 오른쪽 아래 접힌 모서리: 다음 펼침면. 7–8 펼침면에는 표시하거나 입력 처리하지 않는다.
- 페이지 넘김은 약 0.65초이며 글과 도형이 함께 책등을 중심으로 회전한다.
- 애니메이션 중에는 메뉴 클릭을 받지 않아 연속 클릭으로 페이지가 건너뛰거나 게임이 시작되지 않는다.
- 창 크기에 따라 책과 클릭 좌표를 같은 비율로 변환한다. 기존 최소 창 크기 800×600을 따른다.
- 게임 일시정지 창에서 메인화면으로 복귀하면 닫힌 표지로 초기화한다.
- 수집 페이지는 이번에 추가하지 않았다.

2. 챕터와 기존 코드 연결
1 / 여정의 시작 / TutorialLevel(기존 튜토리얼) 실행
2 / 왕 / LevelOne(기존 레벨 1 탐험·전투 프로토타입) 실행
3 / 허영심 많은 사람 / 준비 중
4 / 술꾼 / 준비 중
5 / 사업가 / 준비 중
6 / 가로등지기 / 준비 중
7 / 지리학자 / 준비 중
8 / 장미에게로 / 준비 중

챕터 1·8의 제목과 각 소개는 현재 기획을 바탕으로 작성한 임시 UI 문안이다.
챕터 2의 제목은 확정된 왕 모티브를 따르지만, 실제 레벨에 왕 NPC/보스/후속 서사를 추가한 것은 아니다.
챕터 1도 기존 튜토리얼 내용 그대로이며 장미와 다투고 떠나는 장면은 후속 작업이다.
미구현 챕터는 페이지를 읽을 수 있으나 다른 레벨로 대신 실행하지 않는다.

3. 수정 파일
- BookMenu.h/cpp: 표지 삽화, 챕터 소개, 접힌 모서리, 메뉴 상태와 애니메이션.
- SimpleGame.cpp: 기존 메뉴를 책 메뉴로 교체하고 챕터 실행/메인 복귀 연결.
- Renderer.h/cpp: UI 도형과 글자에 동일한 크기·위치·기울기 변환 적용, 텍스트 크기와 중앙 정렬 지원.
  변환은 변경 전에 배치를 비우며, 메뉴 종료 및 프레임 시작 시 기본값으로 복원한다.
- LevelOne.h: 시작 안내의 레벨 1 표기를 챕터 2로 변경.
- SimpleGame.vcxproj/.filters: BookMenu 소스와 헤더 등록.
- AGENTS.md, 게임_개발_지침.txt: 최신 메뉴 기준 반영.
외부 그림 파일이나 라이브러리는 추가하지 않았다.

4. 확인 범위
코드의 상태 전이, 챕터 배열/페이지 경계, 입력 분리, 좌표 변환을 정적으로 검토했다. 프로젝트 XML 및 BookMenu 등록 중복 여부 확인, 수정한 C++ 파일의 clang-format --dry-run --Werror, 대상 추적 파일의 git diff --check를 통과했다.
빌드 및 게임 실행/렌더링 결과 확인은 사용자 선호에 따라 수행하지 않는다.

사용자 실행 확인 항목:
- 표지 제목/삽화/종료 버튼이 보이고, 종료 버튼 클릭은 책 열기와 겹치지 않는지.
- 표지 열기, 1–2→3–4→5–6→7–8 및 역방향 넘김이 자연스러운지.
- 첫 펼침면 이전으로 표지가 닫히고, 마지막 펼침면에 다음 버튼이 없는지.
- 챕터 1은 튜토리얼, 챕터 2는 탐험·전투 레벨로 진입하는지.
- 챕터 3~8에서 시작이 비활성인지, 연속 클릭이 애니메이션을 중복 실행하지 않는지.
- 800×600 및 평소 해상도에서 글자와 버튼이 겹치지 않고 클릭 위치가 맞는지.
- 일시정지에서 메인 복귀 후 표지가 보이며, 재진입한 게임의 인벤토리와 입력이 정상인지.

5. 후속 정적 검토 및 수정
- BookMenu::Update가 프레임당 경과 시간을 0.05초로 잘라 20 FPS 미만에서 애니메이션이 느려지는 문제를 수정했다. 실제 경과 시간을 사용하고 진행률을 1로 제한한다.
- 표지 회전 중 밑판/종이 두께의 왼쪽 폭을 진행률로 계산해 표지 끝과 어긋나던 문제를 수정했다. 회전각의 코사인으로 계산한 표지의 투영 폭을 사용하며 그림자도 해당 폭과 중심을 따른다.
- 메뉴 상태 전이, 처음/마지막 펼침면 경계, 챕터 실행 입력 분리, 렌더러 변환 초기화 및 프로젝트 XML 등록을 정적으로 검토했다.
- 관련 C++ 파일의 clang-format 검사를 통과했다. 컴파일·게임 실행·시각 검증은 수행하지 않았다.
- 사용자 확인: 책 열기/닫기 중 표지와 밑판 정렬, 느린 프레임에서도 약 0.85초/0.65초로 끝나는 애니메이션.

6. 확정 제목 및 표지 삽화 변경
- 게임 제목: 붉은 여우와 검은 장미. 표지는 두 줄로 중앙 정렬하고 Windows 창 제목도 변경했다.
- 표지의 여우·검은 고양이 그림을 붉은 여우와 검은 장미 꽃으로 교체했다.
- 여우의 뾰족한 귀·주둥이·꼬리와 붉은 목도리, 장미의 겹꽃잎·줄기·잎을 도형으로 그린다.
- 검은 꽃잎에는 회색 테두리를 넣어 어두운 표지와 구분했다.
- 인게임 캐릭터 모델과 장미의 검은 고양이 수인 설정은 유지한다.
- 빌드 및 실행 결과는 사용자가 확인한다.

7. 표지 삽화 형태 보정
- 여우 목도리를 목 둘레를 따라 꺾이는 띠와 매듭, 뒤로 늘어진 두 끝으로 수정했다.
- 앞다리를 두 개의 가늘어지는 형태로 구분하고 발을 둥글게 그린다.
- 꼬리는 곡선을 따라 부풀었다가 끝으로 좁아지며 끝부분을 검게 표시한다.
- 표지 양옆 큰 풀 두 개는 높이 20 이하의 잔디로 교체했다. 챕터 페이지 장식 식물은 유지한다.
- 달 반지름은 48에서 41로 줄였다.
- 건물 벽을 지면 아래까지 연장하고 기존 지형을 그 위에 덮어 공중에 뜨는 틈을 제거했다.
- 정적 검토 및 clang-format 검사만 수행했으며 빌드·실행 확인은 사용자에게 맡긴다.

8. 여우 참고 그림 반영
- 화면 왼쪽의 가까운 귀와 앞다리를 밝게, 오른쪽의 먼 귀와 앞다리를 어둡게 변경했다.
- 가까운 앞다리는 가슴을 덮는 굽은 형태, 먼 앞다리는 몸통 오른쪽의 좁은 형태로 벌려 배치했다.
- 꼬리 곡선의 제어점과 끝을 위로 올리고 곡선의 접선 계산도 함께 수정했다.
- 목도리를 목 전체 폭을 덮는 두꺼운 띠로 변경했다.
- 여우 기준 위치를 390에서 382로 8만큼 올려 장미의 줄기 끝 높이와 맞췄다.
- 장미, 잔디, 달, 건물, 제목 및 메뉴 동작은 변경하지 않았다.
- 정적 검토와 포맷 확인만 수행했으며 빌드·실행은 하지 않았다.

9. 여우 겹침 순서와 형태 단순화
- 어두운 귀와 검은 끝을 얼굴보다 먼저 그려 얼굴 뒤에 배치했다.
- 어두운 앞다리를 몸통보다 먼저 그려 윗부분이 몸통 뒤로 가려지도록 했다.
- 두 앞다리를 직사각형과 타원(어깨·발)의 조합으로 단순화했다.
- 목도리는 둥근 양끝을 가진 단색 띠로 바꾸고, 별도의 밝은 원과 테두리 음영을 제거했다. 늘어진 끝도 같은 색으로 통일했다.
- 표지 외의 캐릭터 모델은 변경하지 않았다. 포맷 검사와 정적 검토만 수행했으며 빌드·실행은 하지 않았다.

10. 밝은 앞다리 및 목도리 아랫면 수정
- 밝은 앞다리 전체를 왼쪽으로 13만큼 이동해 어깨 끝이 흰 배의 왼쪽 경계를 넘지 않도록 했다.
- 목도리의 둥근 실루엣을 유지하면서 아랫면을 어두운 붉은색으로 표현했다.
- 늘어진 끝은 왼쪽 아래를 향하는 사각형 하나로 바꾸고 두 번째 끝을 제거했다.
- 다른 표지 요소는 유지했다. 정적 검토와 포맷 확인만 수행했으며 빌드·실행은 하지 않았다.
