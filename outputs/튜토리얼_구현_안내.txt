튜토리얼 구현 안내
2026-09-14 최신 변경: NPC 대화 대신 좌클릭 독백 종료 후 퀘스트 자동 획득,
거점 보관함에 물자 보관, 울타리 안 크리처 관찰로 변경했다.
아래 최초 안내보다 독백_보관함_관찰구역_안내.txt의 최신 흐름을 우선한다.

후속 개선: 사후 처리, 그림자 마스크, 캐릭터 스프라이트, 머티리얼과 환경 효과,
거점 바깥 크리처 배회·접근을 추가했다. 최신 내용은 렌더링_크리처_개선_안내.txt를 참고한다.
아래 초기 구현 범위의 '셰이더 2개'는 현재 기본 2개 + 사후 처리 2개로 확장되었다.

구현 범위
기존 SimpleGame.sln의 C++/OpenGL/GLEW/freeglut 베이스를 확장했다.
별도 게임 엔진, 외부 패키지, 이미지 다운로드 없이 코드로 장면을 구성한다.
쿼터뷰 좌표 변환과 화면 기준 WASD 이동, 충돌·벽을 사이에 둔 상호작용 차단,
F 단발 입력, 물자 회수와 전달, 한국어 UI, 주변 지도, 재시작을 구현했다.
폐허 벽·바닥·덩굴·식물·가구·인물·거점 조명은 색상 도형으로 렌더링한다.
기존 콘셉트 이미지를 배경으로 띄우는 방식이 아니며, 그 이미지와 같은 재질 품질을 재현한 것은 아니다.
구체적 아트 제작 방식의 최종 확정 전 사용할 수 있는 코드 기반 2.5D 프로토타입이다.

사용자 빌드 및 실행
1. SimpleGame.sln을 Visual Studio에서 연다.
2. Debug / x64로 빌드한다. 다른 기존 구성도 프로젝트 설정에 유지되어 있다.
3. 디버깅 시작 또는 출력 폴더의 SimpleGame.exe를 실행한다.
4. OpenGL 3.3을 지원하는 그래픽 환경이 필요하다.
빌드 후 셰이더 2개와 해당 아키텍처의 기존 DLL을 출력 폴더에 복사하도록 설정했다.
셰이더는 실행 파일 옆 Shaders 폴더에서 읽으므로 실행 작업 폴더에 의존하지 않는다.
한글 UI는 Windows의 맑은 고딕을 사용한다.

조작
W/A/S/D: 화면 위/왼쪽/아래/오른쪽 이동. 동시 입력 가능.
F: 가까운 대상과 상호작용. 누르고 있어도 반복 발동하지 않는다.
R: 레벨 처음부터 다시 시작.
ESC: 종료.
창 전환 중에는 이동 입력을 비우고 진행 시간을 멈춘다.
최소 창 크기는 안내 UI의 가독성을 위해 800×600으로 제한한다.

권장 진행
1. 식물로 덮인 로비의 낮은 앞벽 중앙 출입구로 나온다.
2. 지도 중앙의 노란 거점 표시를 찾아 담당자 근처에서 F로 의뢰를 수락한다.
3. 식료품점(노란 물자 표시), 생활용품점(청록 물자 표시)의 상자 근처에서 F를 누른다.
4. 거점 담당자에게 돌아와 F로 전달한다.
5. 목표 완료 및 식탁·선반의 물자 표시를 확인한다.
상점 방문 순서는 자유다. 의뢰 전에 먼저 회수해도 진행 상태가 반영된다.
완료 시 콘솔에 게임 창 활성 상태에서의 누적 진행 시간이 초 단위로 출력된다.
5분 제한 실패는 없으며 실제 플레이 시간이 5분 이내인지는 사용자가 확인해야 한다.

파일 역할
SimpleGame.cpp: 창, OpenGL 초기화, 키 입력과 갱신 타이머, 크기 변경과 종료.
TutorialLevel.h/.cpp: 레벨 배치, 이동과 충돌, 퀘스트, 쿼터뷰 장면 및 UI.
Renderer.h/.cpp: 기존 셰이더/VBO 렌더러를 확장한 도형 일괄 그리기와 한글 텍스트.
Shaders/SolidRect.vs/.fs: 화면 좌표·정점 색상·텍스트 알파 처리.
SimpleGame.vcxproj: 새 소스 등록, UTF-8, 셰이더와 DLL 출력 복사.

사용자 확인 항목
- WASD 방향, 대각선 이동, 벽 충돌과 열린 출입구 통과.
- F를 길게 눌러도 중복 수락·회수·전달되지 않는지.
- 식료품 먼저/생필품 먼저 두 순서의 완료.
- 의뢰 전 회수, 일부만 회수한 상태에서 귀환, 완료 후 재대화.
- 한글 UI, 창 크기 변경, Alt+Tab 후 키가 계속 눌린 상태로 남지 않는지.
- 폐허·식생·인물·거점과 물자 전달 전후 장면의 가독성.
- 처음 조작부터 전달 완료까지 5분 이내인지.

확인 범위와 한계
소스와 셰이더 연결, 프로젝트 XML, 파일 경로와 변경 형식을 정적으로 검토했다.
사용자 선호에 따라 빌드·게임 실행·실제 화면 확인은 수행하지 않았다.
컴파일 성공, 실제 렌더링 결과, 런타임 동작과 플레이 시간은 아직 검증되지 않았다.
전투·저장·제작·분기 대화·전체 오픈월드는 이번 구현에 포함하지 않았다.
